Pertanyaan Umum

Hal yang Sering Ditanyakan

Jawaban ringkas seputar proses kerja sama, durasi pengerjaan, dan keahlian siswa RPL SMK Telkom Lampung.

Untuk website Landing Page atau Portofolio satu halaman umumnya memakan waktu 3–6 hari kerja. Sedangkan untuk website sistem informasi dengan database (PHP & MySQL) memerlukan waktu sekitar 1–2 minggu tergantung kompleksitas fitur yang diinginkan.
Pasti! Seluruh kode CSS dan antarmuka dibangun dengan pendekatan Mobile-First. Tampilan akan otomatis menyesuaikan layar smartphone, tablet, laptop, hingga monitor desktop tanpa teks terpotong atau gambar pecah.
Jangan khawatir, saya siap membantu merancang wireframe visual, pemilihan palet warna modern, dan struktur konten di Figma sebelum proses penulisan kode dimulai.
Sangat terbuka! Sebagai siswa jurusan Rekayasa Perangkat Lunak di SMK Telkom Lampung, saya sangat antusias mengikuti program Praktek Kerja Lapangan (PKL) / Magang baik secara onsite di Lampung maupun remote untuk mengasah keahlian di lingkungan industri nyata.
Tentu saja. Saya memberikan masa pendampingan perbaikan bug gratis hingga 30 hari setelah peluncuran, serta revisi minor tata letak untuk menjamin kepuasan Anda.
